# Lucraft : versions prêtes à installer

Ce dépôt ne contient que les binaires de Lucraft (les apps et Lucraft Launcher) : le code est
ailleurs. Pour installer Lucraft sur un Mac, ouvrez le Terminal et collez :

    curl -fsSL https://raw.githubusercontent.com/axsomette/lucraft-releases/main/install.sh | bash

Ensuite, Lucraft Launcher installe les apps et se met à jour tout seul.

## Télécharger une app directement

Sans le launcher, chaque lien télécharge la dernière version d'une app. Ouvrez le DMG et glissez
l'app dans Applications. Au premier lancement, macOS peut la bloquer : Réglages Système ›
Confidentialité et sécurité › « Ouvrir quand même ». Les mises à jour, elles, ne se font pas toutes
seules : pour ça, il faut le launcher.
